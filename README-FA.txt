برنامه اندروید «سلام دنیا»
==========================

این پوشه، سورس یک پروژه ساده اندروید است. خروجی APK از قبل ساخته نشده است؛
برای ساخت APK باید پروژه را در Android Studio باز و Build کنید.

ساخت APK:
1. Android Studio را نصب کنید.
2. از مسیر File > Open پوشه SalamDonya را انتخاب کنید.
3. منتظر بمانید Gradle Sync کامل شود. در صورت درخواست، SDK Platform 35 را نصب کنید.
4. از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را انتخاب کنید.
5. فایل APK معمولاً در این مسیر ایجاد می‌شود:
   app/build/outputs/apk/debug/app-debug.apk

نصب روی موبایل:
- فایل app-debug.apk را به گوشی منتقل کنید.
- فایل را باز کنید و در صورت نیاز اجازه نصب از این منبع را فعال کنید.

مشخصات:
- نام برنامه: سلام دنیا
- شناسه: com.example.salamdonya
- حداقل نسخه: Android 6.0 (API 23)
- اینترنت و مجوزهای اضافی لازم ندارد.

ساخت APK بدون نصب Android Studio (با GitHub Actions)
====================================================
1. در GitHub یک مخزن جدید بسازید (مثلاً SalamDonya).
2. فایل ZIP پروژه را روی کامپیوتر استخراج کنید.
3. در صفحه مخزن، Add file > Upload files را انتخاب کنید و همه فایل‌ها، از جمله پوشه مخفی .github، را بارگذاری و Commit کنید.
4. از زبانه Actions، گردش کار "Build Salam Donya APK" را باز کنید و در صورت نیاز Run workflow را بزنید.
5. پس از پایان موفق، در همان اجرای workflow بخش Artifacts را پیدا کنید و SalamDonya-APK را دانلود کنید.
6. ZIP دانلودشده را باز کنید؛ فایل app-debug.apk داخل آن است.
7. APK را به موبایل منتقل و نصب کنید. ممکن است لازم باشد اجازه نصب از این منبع را در تنظیمات اندروید فعال کنید.

نکته: فایل APK در فضای ابری ساخته می‌شود؛ در این روش Android Studio روی کامپیوتر لازم نیست.
